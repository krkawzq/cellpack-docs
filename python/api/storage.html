Numeric value dtypes are uint8/16/32/64, int8/16/32/64, float32 and float64 in native byte order. Arrays borrowed by a native call must not be resized or modified concurrently.

ReadOptions fields: strategy="auto" chooses between range and whole-record-region reads; "ranges" and "whole" force a strategy. max_gap_bytes=0 bounds range merging and request_cost_bytes=4096 prices each request in the auto heuristic. ReadSummary reports bytes and requests for payload I/O, excluding metadata preparation.

CSR contains NumPy indptr, indices, data, and (rows, cols) shape. nnz reads the last indptr value. to_scipy() requires SciPy. ReadSelection exposes shape, dtype, capacity_nnz and io_summary; allocate sparse buffers for capacity, then use the trimmed returned CSR.

Examples: matrix access. Detailed ownership and mapping contracts follow the declarations.

Store ​

python
Store(source: File | Store | str | PathLike, *, shape: tuple[int, ...] | None=None, dtype=None)

An immutable, lazily indexed view of one CellPack stream.

Rows are cells. Each output column is a stored column or an absent one, which reads as zeros, so a Store can present a stream in a panel the caller lays out. Columns are addressed by position only. Views come from:

  • store[cells, genes]: orthogonal selection, as in AnnData or h5py. Integers keep their axis. Both axes take slices, integers, integer arrays (any order, repeats) and boolean masks.
  • map_genes: place columns by a caller-given column → panel map.
  • astype: convert values while decoding.

None of these read data. read, read_dense and read_csr decode into NumPy / ~pycellpack.cellpack.CSR (into caller buffers with out=); prepare returns a ReadSelection for repeated reads; to_memory, toarray, tocsr and np.asarray return NumPy / SciPy objects. Higher-rank dense arrays stored with flattened trailing axes take their logical shape and select cells only.

Writer ​

python
Writer(path: str | PathLike, n_cols: int, dtype, *, format: str='csr', chunk_rows: int=4096, page_size: int=4096, options: EncodeOptions | None=None, workers: int | None=None, atomic: bool=False)

Streaming stream writer. A stream becomes readable after finish().

append takes dense or sparse rows whatever the stored format; the native writer converts them. Whole chunks within one append are encoded by workers threads (default: one per CPU, at most 32); the file is identical to a serial write. Append many rows at a time to let chunks encode concurrently.

With atomic=True, a sibling temporary file is published only after finish succeeds; abort leaves the destination untouched. This requires a regular filesystem path and does not guarantee power-loss durability. New atomic files are private (mode 0600); existing permission bits are kept.

Detailed contracts ​

Store is the array API. File is the low-level stream handle: a .cpk file, a bounded embedded region, or an in-memory stream from File.from_bytes. write(path, matrix, ...) and compress(matrix, ...) return Stores; the latter keeps an anonymous in-memory stream, accessible as store.file.

python
import numpy as np
from pycellpack import cellpack

x = np.arange(24, dtype=np.float32).reshape(6, 4)
store = cellpack.write("matrix.cpk", x, chunk_rows=3)
view = store[[5, 1, 5], [3, 0, 3]].astype(np.float64)
out = view.read_dense()                  # shape (3, 3); reads on demand
csr = view.read_csr()                    # NumPy-backed cellpack.CSR
selected = cellpack.read("matrix.cpk", [5, 1], [3, 0], format="dense")
encoded = store.file.to_bytes()          # the complete .cpk stream
memory = cellpack.Store(cellpack.File.from_bytes(encoded))

Store indexing is orthogonal and keeps both axes, including integer selectors. Both axes take slices (also negative steps), integer arrays with repeats and boolean masks. Indexing, astype and map_genes compose views without data I/O. Streams keep no gene or cell names: positions and alignment are the caller's. Higher-rank dense arrays use Store(file, shape=...), with trailing axes flattened in the stream; these views select cells only.

read(format=None) defaults to the stored layout and returns a NumPy array or CSR; read_dense and read_csr choose it explicitly. to_memory, toarray, tocsr and np.asarray(store) provide NumPy/SciPy conveniences. iter_batches(batch_size=4096, format=None, ...) decodes successive cell batches. store.file, cells, genes, shape, dtype, format and is_identity describe the view; selection arrays are read-only.

map_genes(gene_map, n_genes=None) maps this view's columns into a panel: integer targets must be distinct; -1 or scans.UNMAPPED drops a column. Missing panel columns read as zero. cellpack.GeneMap owns a validated map; cellpack.selection.as_gene_map accepts it, an integer vector or a dict from source positions to targets. normalize_rows(rows, size) returns uint64 positional IDs, preserving order and repeats.

File tools in io ​

python
from pycellpack import io

store = io.write_cpk("matrix.cpk", x)                # matrix, Store or row batches
io.write_cpk("copy.cpk", (x[i:i + 2] for i in range(0, 6, 2)))
info = io.cpk_info("matrix.cpk")                     # shape, dtype, format, chunks, nbytes
part = io.read_cpk("matrix.cpk", [5, 1], format="csr")
for batch in io.iter_cpk("matrix.cpk", batch_size=2):
    ...
lazy = io.open_cpk("matrix.cpk")                     # a Store; also File, bytes

write_cpk streams a Store or an iterable of row batches through Writer without holding more than one batch; the stored layout defaults to the input's. cpk_info reads the superblock only. io.h5ad_to_cpk (AnnData extra) exports one matrix slot of an H5AD/H5CP file the same way.

Prepared reads and caller buffers ​

python
file = cellpack.File("matrix.cpk")
mapping = cellpack.GeneMap([1, -1, -1, 0], 3)
selection = file.prepare_read([5, 1, 5], gene_map=mapping, dtype=np.float64)
workspace = cellpack.ReadWorkspace()
out = np.empty(selection.shape, selection.dtype)
selection.read_dense(out=out, workspace=workspace)
csr = selection.read_csr(index_dtype=np.int32, workspace=workspace)
workspace.clear()

# A Store composes the same read, including its selections and dtype.
prepared = store[[5, 1, 5], [3, 0]].astype(np.float64).prepare()
prepared.read_dense()

ReadSelection.capacity_nnz is the source CSR capacity, not the exact number of mapped entries; dropped genes can reduce the returned CSR.nnz. ReadSelection.shape, dtype and io_summary describe it. Dense out= returns the supplied array; CSR out= takes a CSR or (indptr, indices, data) tuple with sufficient capacity. Index arrays default to int64; int32, uint32 and uint64 are also accepted (native CSR reads additionally accept uint16 column indices). Stored sparse zeros remain stored entries. A Store with repeated genes expands the decoded unique columns on read; it cannot prepare(), or read repeated genes into caller CSR buffers.

A workspace retains scratch and permits one active read; concurrent reads need separate workspaces. Numeric buffers must be native-endian, aligned, C-contiguous and writable for output. Overlapping input/output/scratch is rejected. Do not mutate or resize borrowed arrays during a native call; I/O or codec failures can leave partial output, which must be discarded. Storage codecs preserve the stored dtype unless a view/selection requests conversion. Encoding/decoding uses workers threads, defaulting to one per available CPU, at most 32 (PYCELLPACK_WORKERS overrides).

File.prepare_read(..., read_options=ReadOptions(...)) controls payload reads: strategy="ranges" coalesces selected byte ranges, "whole" reads whole record regions and "auto" compares bytes plus an explicit per-request cost. max_gap_bytes=0 and request_cost_bytes=4096 are defaults, not a calibrated device model. ReadSummary reports record_bytes, read_bytes, requests and whole_chunk_bytes, excluding metadata preparation. File.chunks, read_chunk(chunk, out=None, metadata_only=False) and chunk_meta(chunk) expose stream components; offset and length bound embedded regions.

Writing and file identity ​

Writer(path, n_cols, dtype, format="csr", chunk_rows=4096, page_size=4096, options=None, workers=None, atomic=False) streams append(matrix) calls, then finish(); successful context exit finishes and exceptional exit aborts. Input CSR must be canonical with sorted distinct indices. write and compress also accept ordinary NumPy/SciPy matrices and canonicalize sparse input. options is a scans.EncodeOptions.

atomic=True writes a sibling temporary file and replaces the destination only after success. Aborting or dropping the writer discards that temporary; existing permission bits are preserved, new atomic files use mode 0600. Writers belong to their creating process. Atomic replacement requires a regular path and does not guarantee persistence across power loss.

An opened File continues reading its original descriptor after path replacement. to_bytes() and unpickling reject a replaced path; in-memory Files pickle by their bytes. Stores pickle their file and composed view.
