PyCellPack/API

Codec components API ​

python
from pycellpack.cellpack import scans

Use Store for ordinary matrix I/O. This module exposes chunk/record codecs and caller buffers for custom integrations. It is independent of training loader orchestration.

Shared arguments ​

rows selects chunk-local rows. records supplies record bytes separately from metadata. space=IdSpace.SOURCE returns source IDs; CODED addresses the encoded ID space. gene_map maps source columns to output positions and n_genes defines panel width. dtype requests output conversion and must agree with supplied out. fill=Fill.ZERO initializes absent dense values; other fill modes require callers to understand untouched output cells.

Output arrays must be aligned, native-endian, writable and C-contiguous. Scratch arrays contain uint64 words, not bytes. Use encode_workspace_words and decode_workspace_bound for capacity, and chunk_sizes/record_bound for output bounds. Inputs, outputs and scratch must not overlap unsafely. Do not mutate borrowed arrays during native calls.

Reusable objects ​

PreparedEncoder snapshots normalized input/model state and exposes output_bytes, workspace_words and pre-encoding meta. encode accepts caller buffers. Its metadata supports encoding tables, not cell-indexed decoding before records are placed.

Decoder binds Meta, gene mapping and output dtype once, reusing scratch across decode calls. Use separate instances concurrently. EncodeTables and DecodeTables provide the appropriate source/coded lookup direction. Parts and its component arrays are owned snapshots, not borrowed Rust zero-copy structures.

Exact declarations and configuration defaults follow. The component ownership contract appears at the end.

Detailed contracts ​

python
from pycellpack.cellpack import scans

chunk = scans.encode_chunk(x, options=scans.EncodeOptions())
meta = scans.Meta(chunk, source_dtype=x.dtype)
tables = scans.DecodeTables(meta)
workspace = np.empty(meta.decode_workspace_words, np.uint64)
dense = scans.decode_dense(meta, tables=tables, workspace=workspace)
csr = scans.decode_csr(meta, tables=tables)
row = scans.decode_record(meta, cell=2)
parts = scans.decode_parts(meta, cell=2)
panel = scans.map_dense(parts, [1, -1, -1, 0], n_genes=3)

Raw chunks record value width, not signedness or floating interpretation; pass source_dtype= to Meta and to decode_chunk(raw_bytes, ...). File.chunk_meta supplies the stream dtype. decode_chunk(meta, ...) can reuse parsed metadata; dtype= selects the output dtype.

SurfaceObjects and operations
MetadataMeta: shape, sizes, records, cell layout/nnz, column modes
TablesEncodeTables(meta), DecodeTables(meta), compose_mapping
Encodingchunk_sizes, encode_chunk, encode_record, record_bound, encode_workspace_words
Decodingdecode_chunk, decode_dense, decode_csr, decode_record, decode_record_dense, selection_nnz, dense_bytes, decode_workspace_bound

Packing/dispatchpacked_len, pack_chunk, record_nnz, kernel_set, supported_kernel_sets

Codecs accept caller out= and workspace= buffers. Workspace words are uint64. chunk_sizes returns ChunkSizes(output_bytes, workspace_words); encode_chunk queries only missing buffers. fill="assume_zeroed" skips clearing a supplied dense output, so the caller must provide zeros.

scans.PreparedEncoder(matrix, rows=None, options=...) snapshots its inputs, reuses the encoding model and exposes output_bytes, workspace_words and meta; encode(out=..., workspace=...) writes a chunk. Its pre-encoding metadata is suitable for encoding tables, not cell-indexed decoding. Rust's PreparedEncoder instead borrows immutable input.

scans.Decoder(meta, gene_map=..., n_genes=..., dtype=...) binds dtypes, composes mapping once and reuses scratch for decode_dense, decode_csr and decode_record. Use separate decoders for concurrent calls. Owned Parts keep immutable private metadata, record/page copies and scratch; their component arrays are read-only snapshots. They are not borrowed zero-copy Rust Parts. Explicit dtype= must agree with supplied output.
