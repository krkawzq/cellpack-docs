PyCellPack/API

Statistics and cost records API ​

python
from pycellpack.loader import RunStats, MemoryEstimate, profile_sites, profile_groups
from pycellpack.loader import costs

Run results ​

run.snapshot() returns current RunStats; run.join() returns final RunStats after draining. RunStats contains typed I/O counts, named output records and optional profile/online statistics. to_dict() produces nested JSON-ready values; from_dict() reconstructs typed records. The declarations below list every field and its default.

profile_sites() returns site name → description; profile_groups() returns group → member names. LoaderConfig.profile accepts True, False/None, one site/group, or a sequence. Event counts remain available without timing.

ProfileReport.site returns a site's report or None; time sums named site seconds, map_time addresses one schema and process_bands reports full/partial calls and timings per size band. Inclusive and self times have different meanings; do not sum nested inclusive times as total elapsed time.

MemoryEstimate.to_dict reports known reservations, including caches, private frames, scratch, PlanRing, known metadata and output ring. Compiler state, allocator overhead and OS page cache are excluded; this is not RSS or a hard memory limit.

Resolving and calibrating costs ​

costs.resolve(loading, store=None) returns a CostModel for this loader from available records/defaults. costs.keys(loading) identifies host, storage and output records. record_run(loading, stats) records observations. calibrate(loading, cells=None, ...) runs actual measurements and can be expensive; it is never implied by resolving defaults.

calibrate defaults to steady_seconds=30, max_warmup=None, budget=None, save=True, force=False, seed=0 and verbose=True. Provide representative cells and resource limits deliberately. CostStore(root=None) manages versioned records using get/put/update/records/remove. Mutation methods write or delete local cost records; they do not change matrix data.

See planning and diagnostics for memory and timing interpretation.

RunStats ​

A run's counts (always kept) and, for profiled runs, its sites.

Counts: accesses, decoded and mapped rows, process calls, bytes written; record pages used, served from cache frames (page_hits) and read; pages admitted into cache frames and the extra admission reads among them (block_reads); accesses served by a cached row and the row bytes gathered for them, rows built and their bytes; tasks that waited for a frame another access admits; claims held back by the window, the plan and the output ring; tasks whose reads waited for private frames (starved). elapsed is the workers' and plan thread's wall time after setup_elapsed; peak_span the most accesses claimed past the frontier; cache_bytes the plan's cache frames (cache frames × page size) and private_bytes the workers' private frames. outputs maps output names to their counts; online is the online compiler's statistics (OnlineStats.accesses counts accesses, not positions).

IoStats ​

Read requests, bytes requested and read, and requests by size in pages (1, 2, 3-4, 5-8, 9-16, 17-32, 33+).

resolve ​

python
resolve(loading, *, store: CostStore | None=None) -> CostModel

The cost model of loading on this machine.

$CELLPACK_COST_MODEL names a saved model that replaces everything when its outputs match the loader's schemas (the same names, or the same count); when it does not, that model is ignored with a warning. Otherwise each part comes from the store when a record matches (the host's worker constants, the storage's device rates, each process function's costs) and from pycellpack.loader.costs defaults when none does, which warns once per missing record. cores is the loader's (physical cores its workers run on). provenance names each part's source.

calibrate ​

python
calibrate(loading, cells=None, *, steady_seconds=30.0, max_warmup=None, budget=None, save=True, force=False, store: CostStore | None=None, seed=0, verbose=True)

Measures loading's cost model on this machine and stores it.

Seven configurations over a random subset of cells (default: every cell) each hold a steady state for steady_seconds (warm-up excluded; see pycellpack.loader.costs.Steady): no cache, and its untimed twin; a page plan of budget bytes (default: a quarter of the subset's page footprint, at least 64 pages and at most a quarter of the available memory); a row plan of budget bytes and its untimed twin; a page plan over a block shuffle; an online page plan. Worker seconds become core-seconds where workers outnumber the physical cores they run on (Loader.cores). Their snapshot differences fit the host's worker constants, the storage's device rates and each process function's costs, saved as three records (see CostStore) unless save is false. Each part is saved only when its own windows are sound (unless force): the worker constants when windows that keep the workers busy fit them within MAX_RESIDUAL, the device rates when the uncached windows are steady, process costs when the profiled windows are; a part not saved keeps its stored record or defaults. Shared storage that fluctuates may thus yield device rates only.

Returns the measured model (provenance says what was measured).
