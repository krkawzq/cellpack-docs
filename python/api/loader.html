PyCellPack/API

Native loader API ​

python
from pycellpack.loader import DataSource, OutputSchema, LoaderConfig, Loader, load, allowed

DataSource parameters and IDs ​

DataSource(matrices, vocab, *, page_size=None, direct_io=None) registers (source, ids) pairs in order. A source is a path, File or row-only Store view; memory streams and gene views are rejected. Each ids vector maps stored columns to standard IDs below positive vocab, with -1/uint32.max dropping columns. Page size defaults to the first stream. direct_io=None probes O_DIRECT and falls back; False forces buffered reads.

Global cell IDs number contributed rows consecutively. add(source, ids) returns the added matrix's first ID. matrix_cells(matrix) gives its first cell and count. Existing Loaders retain a source snapshot. cell_pages and cell_bytes expose borrowed descriptors: do not close them.

Built-in outputs have shape (batch.rows, out_dim). Process outputs are byte rows or an out_dtype view. batch.region(name) always exposes uint8 bytes. A present sparse column with no record entry is zero; only source-absent columns use default. allowed(source, target) returns whether the loader supports that dtype conversion.

Loader and LoaderConfig ​

Loader(source, outputs=None, *, config=None, **settings) accepts one schema, a sequence, or a name-to-schema mapping. None creates float32 full-vocabulary X. Names and IDs must be unique; unset IDs receive the smallest unused values. schemas is read-only and names preserves output order.

Supply a LoaderConfig or individual fields, never both:

FieldDefaultUnit / behavior
workersUsable CPUs, max 16Native threads
backendProbe"uring" where available, otherwise "pread"
inflight64Positions in flight per worker
claim_batch8Accesses claimed per cursor update
slot_rows256Positions per output slot
windowDerivedSlots; plan reuse gap or unplanned inflight requirement
profileNoneFalse/None untimed; True all sites; site/group string or sequence selects sites
cpus()Worker affinity CPU IDs; empty inherits affinity

start returns a Run. ring allocates ring memory; ring_layout only describes it. compile returns Plan, compile_stats OnlineStats, replay PlanSummary and memory_estimate MemoryEstimate. See plans, ring lifecycle, and the native loading guide.

load(source, cells=None, out=None, config=None, **settings) is a one-shot float32 full-panel read; None cells means all cells. It returns a NumPy array. Supply matching output storage through out to reuse it.

DataSource ​

python
DataSource(matrices, vocab, *, page_size=None, direct_io=None)

Every input matrix, numbered by global cell id in registration order.

matrices is a sequence of (source, ids) pairs. A source is a path, a cellpack.File region or a cellpack.Store selecting cells; ids[c] is the standard id (below vocab) of the matrix's stored column c, and -1 or 0xFFFFFFFF drops the column. The ids belong to the matrix and are always given by the caller: the source infers, names and aligns nothing. A Store's cell selection defines which cells it contributes: global cell ids then number the selected cells, and runs, plans and traces translate them to stored cells natively as they read the sequence. Output schemas name the standard ids of their output dims.

Data reads use O_DIRECT unless direct_io=False; with None (the default) the source falls back to buffered reads when a file's filesystem does not support it (direct_io reports the choice). Metadata reads stay buffered. Sources pickle (in-memory streams do not). paths lists the files of the registered matrices, in registration order.

OutputSchema ​

python
OutputSchema(out_ids, dtype: DTypeLike=np.float32, *, id=None, name=None, default=0, process=None, row_bytes=None, out_dtype: DTypeLike | None=None, scratch_bytes=0)

One output of every position: out_ids[j] is the standard id of output dim j; rows are mapped to these dims and converted to dtype (values stored as other types follow the conversion contract: the same type, lossless widening, signed to unsigned of the same width with negatives unchecked, signed to a wider unsigned, and any integer to a float).

Without process, the output is the cell's dense row. An output dim whose standard id the cell's matrix has is present: the stored value, or 0 where the record stores none (CSR drops zeros, so they are expression values). An output dim the matrix has no column for is missing and takes default; a column no output dim takes is dropped. With a ProcessFn, each cell's output is row_bytes written by the function (its row_format picks CSR or dense rows, with the same semantics), viewed in batches as out_dtype elements (default: raw bytes); scratch_bytes per worker.

name names the output in batches and statistics (a loader given a mapping of names uses those); id identifies the schema for plans (unset ids get the smallest free ones). Schemas pickle when their process function does.

LoaderConfig ​

How a loader runs: workers threads (default default_workers(cpus)), each with inflight positions in flight; I/O through backend (default io_uring where supported, else pread); claim_batch accesses claimed per cursor update; slot_rows positions per output slot; the execution window in slots (default: a plan's reuse gap, or enough slots for the in-flight accesses); cpus to pin worker i to cpus[i % len].

profile selects the timed sites: False or None runs the untimed instance, True every site, or names of sites and groups (see profile_sites() and profile_groups()); it is kept as a tuple of names, or None. Every build carries both instances.

Fields and defaults ​

python
workers: int | None = None
backend: IoBackend | str | None = None
inflight: int = 64
claim_batch: int = 8
slot_rows: int = 256
window: int | None = None
profile: bool | str | tuple[str, ...] | None = None
cpus: tuple[int, ...] = ()

IoBackend ​

How the loader issues reads. PREAD completes each read inside the call (preadv); URING queues a worker's reads on its own io_uring and harvests completions. The value is the name the native side takes, so a member compares equal to its string.

Fields and defaults ​

python
PREAD = 'pread'
URING = 'uring'

Loader ​

python
Loader(source, outputs=None, *, config=None, **settings)

One native execution frontier over a data source and named outputs.

outputs is an OutputSchema, a sequence of schemas (named by their name, else their id) or a mapping from names to schemas; without one, a dense float32 row over every standard id named "X". config is a LoaderConfig, or give its fields as keywords (workers, inflight, slot_rows, ...).

A run executes one access per output per position (in the order p0s0 p0s1 ... p1s0), each loading one cell: pass a uint32 array of the accesses' cells or an Accesses (Accesses.replicate gives every output the position's cell, Accesses.offset shifts each output's cell, e.g. to a paired matrix). Outputs land in one ring whose slots hold every output's rows of slot_rows consecutive positions. A run caches only as a plan says (an offline Plan, or PlanOptions compiled online while it runs); cached rows keep their stored type, shared by every output. Loaders pickle (to build the same loader in another process) when their source and outputs do.

source and config are what the loader was built from, schemas maps each output name to its bound OutputSchema, and names lists the names in output order.

Compiles a cache plan for a stored sequence (an array or an Accesses, materialized): offline (the whole sequence is the horizon), or as an online run would (a finite horizon, frozen and published chunk by chunk; plan.online_stats holds its statistics). options are PlanOptions or a cache budget in bytes.

Loader.memory_estimate ​

python
Loader.memory_estimate(plan=None, *, slots=4, world=1) -> MemoryEstimate

Known reservations of a run with plan: a Plan, PlanOptions (with their gap, chunk and row mode), a cache budget in bytes for default page planning, or None for no plan.

Loader.start ​

python
Loader.start(accesses, *, plan=None, ring=None, slots=None, world=None, rank=0) -> Run

Starts loading accesses (a uint32 array of the accesses' cells, or an Accesses; the native side keeps its own copy of an array).

plan is an offline Plan (for the sequence it was compiled for), PlanOptions or a cache budget in bytes to compile the plan online while the run goes, or None (no cache). Outputs go to ring, or to a new ring of slots slots (default 4) shared by world ranks (default 1); this process consumes rank rank by iterating the run.

Warns (RuntimeWarning) when the run's known reservations (memory_estimate) exceed the memory still available to the process.

load ​

python
load(source, cells=None, *, out=None, config=None, **settings) -> np.ndarray

Loads a DataSource's cells (default: all) into one dense float32 array over its standard ids, through the native concurrent loader; cell order and repeats are preserved. out (C-contiguous float32, 8-byte aligned) receives them; config sets the loader, or pass its fields as keywords when config is None.
