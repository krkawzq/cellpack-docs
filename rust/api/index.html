CellPack/API

Rust API ​

Find the interface for your task, try it on a small matrix, then follow its exact declaration and ownership rules. This reference covers the Rust crate cellpack.

Type names inside declarations are clickable: open a definition beside the page, inspect its source, or continue to the full API entry. Run example executes a fixed, prebuilt program on the configured server. Code is read-only. Enable LSP for type information and definition lookup within the current example file. Runnable examples explain the shared fixture and local setup.

scans::encode_chunkfn

Chunk and record encoding, the reusable PreparedEncoder , and the output and workspace bounds of both. Encodes the selected rows as one chunk into out (at least chunk_bound bytes) with ws of chunk_workspace_words words. Returns the chunk length.

scans::encode_recordfn

Chunk and record encoding, the reusable PreparedEncoder , and the output and workspace bounds of both. Encodes one row with a chunk’s metadata and tables into out (at least record_bound bytes). ws needs encode_workspace_words for the chunk’s Meta::max_elems . Returns the record length; a row without non-zeros has an empty record. The row takes the smaller of its sparse and dense layouts as opt.layout allows; a dense candidate needs max_elems == n_genes . Dictionaries beyond Meta::max_k are not used, so the record fits the chunk’s decode workspace.

scans::encode_tablesfn

The per-chunk lookup tables, bound to the runtime or to a given one. Encode tables of a chunk, bound to the process kernel set.

scans::encode_tables_forfn

The per-chunk lookup tables, bound to the runtime or to a given one. encode_tables bound to the kernel set of rt .

scans::encode_workspace_wordsfn

Chunk and record encoding, the reusable PreparedEncoder , and the output and workspace bounds of both. Encode workspace in u64 words for records of at most max_elems stored elements (see crate::format::Meta::max_elems ).

scans::kernel_setfn

The bound instruction set, by name or as Isa . Name of the bound kernel set (binding the runtime from the environment if nothing has yet); "unbound" when the environment is invalid.

scans::map_densefn

Mapping decoded rows onto a caller column panel, and the element types its conversions take. Scatters a decoded row into a dense output row: out[map[id]] gets each element’s value, with dict and modes as in map_parts ; elements whose column is UNMAPPED are skipped. With Fill::Zero the row is cleared first. Every mapped column must lie inside out .

scans::map_partsfn

Mapping decoded rows onto a caller column panel, and the element types its conversions take. Maps a decoded row: for each element, col = map[id] ; elements whose column is UNMAPPED are dropped, the rest are written in order to cols and vals . Values are dict[rank] for a dictionary ( dict holds its entries converted by Dict::cast_into ) or the raw values read as S and converted. For mode-coded values, modes holds the chunk’s column modes converted to T (see cast_values ), indexed by coded id; it may be empty for chunks without column modes. cols and vals need room for every element of the row; map must cover the row’s largest id. Returns the number of elements kept. Columns keep the row’s id order, so they are ascending only if the map is monotonic.

scans::map_parts_atfn

Mapping decoded rows onto a caller column panel, and the element types its conversions take. Maps the elements of a decoded row at positions (each below the row’s nnz, in any order, repeats allowed): cols[i] = map[id] and vals[i] the value of element positions[i] , with dict and modes as in map_parts . Nothing is dropped: an UNMAPPED column is written as it is. For callers that need only some elements of a row, such as a sampler choosing positions first. A position at or beyond the row’s nnz is Error::InvalidInput .

scans::pack_chunkfn

Page packing of a chunk’s records. Rewrites chunk with its records packed to page -byte pages (see the module docs) into out , which must hold packed_len bytes. Every record then reads ceil(len / page) pages once the chunk is stored at a page-aligned position. Decoding is unchanged. Returns the packed length.

scans::packed_lenfn

Page packing of a chunk’s records. Bytes of chunk once packed to page -byte pages.

scans::prefetchfn

The per-chunk lookup tables, bound to the runtime or to a given one. Hints the processor to load len bytes from p into its caches.

scans::record_boundfn

Chunk and record encoding, the reusable PreparedEncoder , and the output and workspace bounds of both. Largest record a row of at most nnz stored elements can produce; dense when the row may be stored with all n_genes elements.

scans::selection_nnzfn

Record and chunk decoding: CSR arrays, dense rows and Parts views, plus the workspace sizing those calls need. Non-zeros of the selected cells.

scans::CellRefstruct

Borrowed inputs, selections and encoding options. One cell: strictly ascending gene indices and their values ( indices.len() * value_width bytes).

scans::ChunkSizesstruct

Both encoding buffer sizes, queried together. Output capacity in bytes and scratch capacity in u64 words.

scans::CsrRefstruct

Borrowed inputs, selections and encoding options. A canonical CSR matrix: every row’s indices strictly ascending and below n_genes ; data holds value_width little-endian bytes per element. Values are opaque bit patterns, so any 1/2/4/8-byte type round-trips.

scans::CsrViewstruct

Borrowed inputs, selections and encoding options. Canonical CSR with row offsets borrowed in the caller’s integer type.

scans::DecodeTablesstruct

The per-chunk lookup tables, bound to the runtime or to a given one. Decode-side lookup tables of one chunk.

scans::Decoderstruct

Record and chunk decoding: CSR arrays, dense rows and Parts views, plus the workspace sizing those calls need. Bound metadata, tables, ISA dispatch and workspace layout for repeated records.

scans::EncodeTablesstruct

The per-chunk lookup tables, bound to the runtime or to a given one. Encode-side lookup tables of one chunk: an EncModel per model and the gene order records are written in. As with DecodeTables , the metadata key lets EncodeTables::check reject reuse across chunks.

scans::Mapperstruct

Mapping decoded rows onto a caller column panel, and the element types its conversions take. Maps decoded rows of element type S to outputs of T , with the kernel for every value encoding and output shape chosen once, for the kernel set the mapper was bound to. Build one per element-type pair and reuse it for every row; the methods behave as map_parts , map_parts_at and map_dense .

scans::ModeDictstruct

Record and chunk decoding: CSR arrays, dense rows and Parts views, plus the workspace sizing those calls need. A mode-coded record’s values: rank 0 is the element’s column mode (the chunk’s Meta::column_modes entry for its coded id) and rank r is dictionary entry r - 1 . Ranks::One means every value is its column mode (an empty dictionary). Debug builds check every rank against k .

scans::PagedRecordstruct

Borrowed inputs, selections and encoding options. A record held in caller pages: len bytes starting start bytes into the first of pages , each page_size bytes long (the last may be shorter if the record ends inside it).

scans::Partsstruct

Record and chunk decoding: CSR arrays, dense rows and Parts views, plus the workspace sizing those calls need. A decoded record before values are materialized: ids and values in the same order, borrowed from the workspace (or the record). With IdSpace::Coded the ids ascend in the chunk’s coded numbering and no order restoration runs; with IdSpace::Source they ascend in source numbering. Callers mapping genes themselves can convert the k dictionary entries once instead of every value. Read-only access keeps the validated ids and rank lengths aligned.

scans::PreparedEncoderstruct

Chunk and record encoding, the reusable PreparedEncoder , and the output and workspace bounds of both. A fixed, immutably borrowed input and its reusable statistical model. Construction performs model building and sizing; repeated writes preserve the same encoding decisions as encode_chunk.

scans::Thresholdsstruct

Borrowed inputs, selections and encoding options. Per-cell coding thresholds: a section is coded only when its coded size is at most mu times its raw size; otherwise it is stored raw. Each lies in [0, 1] ; 0 stores everything raw.
